# CarCare API

NestJS 12 (ESM) · Prisma 7 · PostgreSQL · Redis.

See the [root README](../README.md) for setup, and
[`docs/architecture.md`](../docs/architecture.md) for the module layout and
layering rules.

```bash
pnpm dev          # watch mode
pnpm test         # unit tests
pnpm test:e2e     # integration tests (needs PostgreSQL + Redis)
pnpm lint         # type-aware ESLint
pnpm typecheck    # tsc --noEmit
```
